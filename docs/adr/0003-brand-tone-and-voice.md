# ADR-0003: Brand Tone & Voice

**Status:** Accepted
**Deciders:** Project owner (grilled via issue #8)
**Date:** 2026-07-27
**Tags:** brand, tone, voice, copywriting, i18n, danish

---

## Context

Issue #8 raised the question of what the SaRe ApS brand should sound like. The site is a bilingual (Danish + English) pure pitch site for a small dev shop whose core message is "small, personal team — you work with the owners." The audience is Scandinavian B2B businesses evaluating a development partner.

Seven decisions were resolved sequentially through a structured grill.

---

## Decision

### 1. Target audience: Founder / business owner

Not a technical lead. The pitch is aimed at the person who owns the business outcome, because "you work with the owners" resonates most with other owners. This means the voice prioritises trust and reliability over technical depth.

### 2. Danish mode: "du" (informal)

Danish uses the informal "du" throughout, never the formal "De." This reinforces the personal, peer-to-peer relationship that is the brand's differentiator. Formal address would create distance that contradicts the core message.

### 3. Danish vs English: Same brand voice

Both languages use the same voice — not adapted to separate audience expectations. The core message is universal, and splitting voices would dilute brand recognition. English should sound like the same person speaking, not a different persona.

### 4. English flavor: Scandinavian professional

English tone is understated, direct, warm, and avoids hype. It does not borrow Silicon Valley / international-tech cadence ("scale your business," "supercharge"). The Scandinavian B2B audience trusts understated confidence more than imported startup energy.

### 5. Voice attributes

Four attributes define every word on the site:

| Attribute              | Meaning                                                                           |
| ---------------------- | --------------------------------------------------------------------------------- |
| **Confident but warm** | Expertise without arrogance. "We've done this before," not "We're the best."      |
| **Plain-spoken**       | Short words, no jargon. "We build software," not "We engineer digital solutions." |
| **Precise**            | Specific claims, concrete language. No vague promises.                            |
| **Direct**             | Gets to the point. Scandinavian blunt but polite.                                 |

### 6. Tone shifts across pages

The four attributes stay constant; the _emphasis_ shifts per page:

| Page     | Lead attributes     |
| -------- | ------------------- |
| Hero     | Confident + Direct  |
| About    | Warm + Confident    |
| Contact  | Warm + Direct       |
| Services | Precise + Confident |

### 7. Recurring vs one-off work

Ongoing / after-care relationships lean heavier into **Warm + Plain-spoken** ("we're in this together long-term"), while one-off project pitches emphasise **Precise + Confident** (scope, timeline, deliverable). Same voice, different emphasis — consistent with the page-by-page shifting approach.

---

## Consequences

### Positive

- A single, coherent brand voice across two languages and all page types.
- Founders recognise themselves in the tone ("these people talk like I do").
- The "du" choice and Scandinavian-professional English create a consistent regional identity.
- Clear guardrails for copywriters and translators.

### Negative

- The same-brand-voice constraint means English copy cannot chase international tech trends independently.
- "Plain-spoken" and "Direct" limit word count and flourish — every sentence carries weight.
